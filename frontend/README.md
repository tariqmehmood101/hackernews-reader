# Frontend — Hacker News Reader

Angular 20 UI for the newest Hacker News stories. See the [root README](../README.md) for the full
architecture, API reference and design notes.

```bash
npm install
npm start        # http://localhost:4200 — expects the API on http://localhost:5070
npm run test:ci  # headless tests
npm run build:prod
```

The API base URL is set per configuration in `src/environments/`.
